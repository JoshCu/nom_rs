# nom_rs

> **Note:** this project was guided by Josh Cunningham, but apart from the original Fortran it
> is translated from, all of the code and documentation here was generated by AI (Claude).

A Rust port of [Noah-OWP-Modular](https://github.com/NOAA-OWP/noah-owp-modular), the NOAA-OWP
land surface model, which is itself a modular refactor of
[Noah-MP](https://github.com/NCAR/noahmp). It covers the model's BMI interface, and its output
is bit-identical to the Fortran.

- **Complete.** All five physics calls, the timestep loop and the BMI are ported.
- **Bit-identical.** Every physics call is checked against the Fortran's own recorded state,
  with no tolerance. Under [`bmi-driver`](https://github.com/JoshCu/bmi-driver), a year over 53
  catchments gives the same streamflow as the Fortran `libsurfacebmi.so`, to every printed digit.
- **Drop-in.** Loads as a plain C BMI library through `bmi_c`, with no Fortran middleware.
- **Instance-owned state.** No globals, so instances are `Send` and can share a process.

## Build

```sh
cargo build --release   # target/release/libnoahowp_bmi.so
cargo test              # 187 tests; gfortran is not needed
```

## Use

In a `bmi-driver` or ngen realization, replace the Fortran Noah-OWP module with:

```json
{
    "name": "bmi_c",
    "params": {
        "model_type_name": "NoahOWP",
        "library_file": "/path/to/libnoahowp_bmi.so",
        "init_config": "./config/cat_config/NOAH-OWP-M/{{id}}.input",
        "main_output_variable": "QINSUR",
        ...
    }
}
```

The registration function is the default, `register_bmi`. Config files, parameter tables,
variable names and units are the same as the Fortran's.
